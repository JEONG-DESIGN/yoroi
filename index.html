Yoroi documentation

Yoroi is a Shopify theme for eyewear stores. Customers find frames by shape, color and fit size, see exact measurements, and choose lenses with the frame.

Version 1.0.0. Three presets are included: Yoroi (white), Kinari (off-white) and Sumi (black).

Install

  1. In your Shopify admin, go to Online Store > Themes and add Yoroi from the Theme Store.
  2. The theme is added as an unpublished theme. Select Customize to look through it with your own products.
  3. Work through First setup below, then select Publish.

To change the look later, go to Theme settings > Theme style in the theme editor and pick another preset. Changing the style replaces colors and some settings, but never your products or content.

For shape, color_family and material_family, turn on Smart collections in the definition so you can build collections from them.

Photos

  • Photos per color. Start the alt text of a photo with # and the first word of the color name, for example #C1 Aki in Black, front for the color “C1 Black”. When that color is selected, only its photos are shown.
  • Worn photos. If the alt text contains “wearing”, it is shown under the photo as a caption, for example #C2 Medium face width, low nose bridge. Wearing size M. The part starting with # is not shown.
  • Image ratios. Product cards use the ratio set in Theme settings > Product cards. Photos of other ratios are shown whole, never cropped.
  • Focal point. Set the focal point of an image in the image picker so the important part stays in view on phones.

Fit sizes

Yoroi sorts frames into five fit sizes by overall width (eyewear.frame_width). The defaults are:

SizeOverall width
XSup to 129 mm
S130 to 134 mm
M135 to 139 mm
L140 to 144 mm
XL145 mm and over

Change the limits in Theme settings > Fit sizes. The size guide page uses the same numbers. To set a size by hand, fill in eyewear.fit_label.

Filters and search

  • Collection and search pages support Shopify's storefront filters. To filter by shape, color, fit size or material, add the metafields eyewear.shape, eyewear.color_family, eyewear.fit_label and eyewear.material_family as filters in the free Shopify Search & Discovery app.
  • Search suggests products while customers type. The full search page also lists articles and pages.

Editing code

Duplicate your theme before editing code. Go to Online Store > Themes, open the menu next to Yoroi and select Duplicate. Edit the copy, and publish it only after checking it.

Code changes are not covered by theme support, and they are not carried over when you update Yoroi. For custom work, we recommend hiring a Shopify Partner. Small style changes can go in Theme settings > Custom CSS without editing theme files.

Questions

The frame size diagram is not showing.

Check that the product has at least one of eyewear.lens_width, eyewear.bridge_width, eyewear.temple_length, eyewear.lens_height, eyewear.frame_width or eyewear.size, and that the Frame size block is on the product template.

A shape is missing from “Shop by shape”.

Shapes without a collection are hidden on the storefront. Choose a collection for the shape in the section, and make sure the collection has products.

All photos show, whatever color is selected.

Photos switch by color only when their alt text starts with # and the first word of the color name. See Photos.

The prescription choices do not appear.

They appear when the selected lens option contains one of the words in the Prescription block's setting (for example “Prescription”). Add your own wording there if your option names are different.

Express checkout or Shop Pay Installments buttons are missing.

These are shown by Shopify when the payment methods are turned on in Settings > Payments.

Can I use apps?

Yes. Product and featured product sections accept app blocks, and the Custom Liquid section and blocks can hold app code.

Support policy

  • We answer questions about setting up and using Yoroi, and fix bugs in the theme.
  • We reply within two business days (Monday to Friday, Japan time).
  • Custom code, third-party apps and changes to the theme's design are not covered.
  • Send requests through the support form. Include your store address and a screenshot if you can.
